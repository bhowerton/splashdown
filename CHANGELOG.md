# Changelog

What changed in each release of Splashdown. Downloads are on the [releases page](https://github.com/bhowerton/splashdown/releases).

## Unreleased

- **Watched folders.** In Settings → General → Transcribe new files in a folder, add folders whose new audio and video files should be transcribed: a Zoom recordings folder, a voice recorder's imports. Each new file becomes a transcript note once it has finished copying, in the notes folder you choose, and can get its subtitles saved beside it (`talk.mp4` → `talk.srt`). Files already there when you add the folder are left alone, with a button to transcribe them too; nothing is done twice, and files that arrive while Splashdown is closed are done when it starts.
- **Subtitles.** Save a transcript or a meeting as SRT or VTT subtitles: from a note's menu or ⌘K, "Save subtitles". Captions are a line or two, broken at sentence ends and pauses, with the speaker's name when it changes. A file transcribed on this computer is timed word by word; with cloud speech, or for a meeting, the times are estimated from the transcript. Also as a part of Get Note Text in Shortcuts, and `splashdown-cli transcribe-file --srt` / `--vtt`.
- **Translate as you dictate.** Hold the dictation key and press T, then speak: your words come out in the language picked in the menu bar under Translate into, with the overlay showing "→ Spanish". It uses the preset the app would use, so its tone and instructions still apply. The first time, pick the language from a short list that appears; it's kept for next time. Choose up to five in Settings → Words & language to switch between them in the menu bar; the letter can be changed in Settings → General.
- **Translate selected text.** Select text, hold the dictation key and press T: it's translated at once. In your own text it's replaced by the translation. In text you can't edit, like a web page or an email you received, the translation opens in the Ask panel, which can read it aloud.
- **⌃⌥T** (Ctrl+Alt+T on Windows) does both without holding a key: it translates the selection, or with nothing selected starts a hands-free dictation that comes out translated (⌃⌥T again to finish).
- **Better translations.** Translating, with the translate key or a preset's "Translate into", now keeps names, product terms, code and links as they are, keeps your tone and formatting, and translates questions and requests instead of answering or carrying them out. A reply far longer or shorter than a translation would be (a model that wrote the poem you dictated, say) is caught, and your words go in as you said them, marked "not translated".
- **Shortcuts can work with your notes (Mac).** Five more actions:
  - **Find Notes** by what they say, kind (meetings, transcripts…) and time.
  - **Get Note Text**: a whole note, or a meeting's summary, your own notes from it, or its transcript.
  - **Ask My Notes**: a question answered from your notes.
  - **Transcribe File**: an audio or video file into a new note.
  - **Open Note** in Splashdown.

  Settings → Privacy → Shortcuts → "Let shortcuts find and read notes" turns it off. A note hidden from coding agents is hidden from shortcuts too.

## 0.9.0 — 2026-11-05

- **A dictation no longer starts with the one before it.** When you dictate into an app you dictated into a few minutes earlier, the AI sees that earlier text for reference. Smaller models sometimes wrote it out again in front of the new text. Splashdown now takes it off, even while text is typed as it streams in.
- **Splashdown in Shortcuts (Mac).** Six actions to use in your own shortcuts:
  - **Dictate Text** passes what you said on to the next action, cleaned up the way Splashdown types it.
  - **Add to Note** adds text to your note and passes the note on.
  - **Record a Voice Note**, and **Start or Stop Dictation**.
  - **Start Meeting** and **Stop Meeting**, which can wait for the finished note.

## 0.8.0 — 2026-11-04

- **Coding agents can go through your meetings.** With notes allowed for coding agents (Settings → Privacy), `splashdown-mcp` can now list your notes by date, kind, folder or tag ("recap my meetings this week", "what's tagged #launch since Monday?"), with each meeting's summary in the same answer. It can read just a meeting's summary, your own notes from it, or its transcript, from one time to another or for one speaker, and long transcripts come in pages instead of being cut off at 50,000 characters. A search match in a transcript says when it was said. Results link back to the note in Splashdown.
- **Meetings and transcripts have their own switch for agents:** "…including meetings and transcripts", since they hold other people's words. It stays on if you'd already allowed notes, and starts off when you first allow them.
- **Hide from coding agents** in a note's ⋯ menu keeps that note out of every agent's reach.
- **Two ready-made requests for agents:** "Recap my meetings" and "My open action items" come with `splashdown-mcp` as prompts, which Claude Code offers as commands.
- **Set up a coding agent from Settings.** Settings → Privacy → Coding agents → Set up an agent lists Claude Code, Codex, Cursor, VS Code and Claude Desktop with whether Splashdown is set up in each, and a Set up button: Splashdown runs Claude Code's or Codex's own command for you, or opens Cursor's or VS Code's install link, or copies the lines Claude Desktop needs. `splashdown-mcp` now comes with the app (before, you had to build it), and does the same from a terminal: `splashdown-mcp install claude-code`, `agents`, `uninstall`.
- **`splashdown-cli` comes with the app.** The commands that control the running app and its settings (`toggle`, `listen`, `note`, `notes`, `status`, `settings`, `history`, `words import`) work without building anything; Settings → About shows where it is. The pipeline, model and eval commands stay in the full version you build from source.
- **`splashdown-cli notes list`, `search` and `read`** do the same from a terminal or a script: `splashdown-cli notes list --when this_week --kind meeting --summary`.

## 0.7.1 — 2026-11-04

- **Dictating with no text field selected.** When the cursor isn't in a text field (a web page outside any box, a list of files), the text is left on the clipboard and "No text box — copied to clipboard" shows, instead of "Inserted" with the words gone. The same happens when a paste into a browser field doesn't show up.
- **Microphone permission.** After you allow the microphone in the setup guide, it now shows as allowed straight away. Before, it could keep showing Allow… until Splashdown restarted.

## 0.7.0 — 2026-11-04

- **Word for word.** A new built-in preset types exactly what you say, with no AI tidying: hold the dictation key and press 2 ("What can I say?" shows its number). It's never picked by app, only when you ask for it. Settings with your own preset list get it once; delete it and it stays gone. The other built-in presets move up one number (Email is now 3).
- **Compose learns your style from your edits.** When Compose writes into a reply and you change the draft before sending (you always cut "I hope this finds you well", always sign "Cheers"), the draft and what you sent are kept on your computer, separately for email, work chat, texts and everything else. Every few edits, a short description of your style is written from them, and Compose follows it. Settings → Words & language shows each description, lets you rewrite it in your own words, and has Forget my style and a switch to stop learning. A formal message you ask for outright isn't bent to your everyday style.
- **Drafts in your voice.** Compose writes the way you do in your own earlier messages in the conversation on screen: "Dear Tom, … Kind regards" in a formal thread, lowercase and an emoji with a friend, your own sign-off. Only how you write is taken, never facts from those messages, and nothing is stored. Settings → General → Write drafts in my style turns it off.
- **One correction is enough.** Fix a name or term right after dictating it ("Pria" to "Priya") and Splashdown learns it: it's added to your vocabulary at once and "Learned “Priya”" shows for a moment. Before, it was only suggested in Settings, where it was easy to miss. Learned words are listed under Settings → Words & language, each with ✕ to forget it, and the menu bar has Last dictation → Forget “Priya”. A forgotten word is never learned again. A fix counts when it's spelled close to what was typed or sounds the same ("trucks" to "TRUX", "Caitlin" to "Kaitlyn"). Numbers, addresses, paths and email addresses are never learned, and neither is a word you only capitalized to start a sentence ("lol" to "Lol"); a possessive is learned as the name ("Erika's" as "Erika"). How the word was misheard is remembered too ("trucks" for "TRUX"), and a cloud AI is told, so it writes the name where the sentence means it and leaves real trucks alone; the built-in model isn't told, because it then changed the ordinary word too. Splashdown watches the field for 30 seconds after a dictation, reading it every half second, so a fix is caught even when you send the message right away; it looks once more two minutes later while you're still in that field.
- **Names on screen are spelled right.** When you dictate, Splashdown reads the window you're typing in (the email or chat on screen) on your computer and adds its names and terms to your vocabulary for that dictation, so "thanks pria" comes out "Thanks Priya" when Priya is in the thread. Only those words go with the dictation, never the window's text. Settings → Privacy turns it off.
- **Compose: say what to write, not the words.** Hold the dictation key, tap the instruction key and say what you want: "reply saying I'm in and ask about parking", "tell the team the launch moved to Thursday", "decline politely and suggest next month". It's written straight into the field you're in, for the app (an email gets a greeting and your name; a chat message stays short) and for the message you're answering. There's no need to select that message: Compose reads the conversation around where you're typing (the email thread or chat on screen), on your computer; Settings → Privacy turns that off. To change the draft, select it and say the change ("shorter", "warmer"), or say "scratch that". If you've moved to another app by the time it's written, it's left on the clipboard. To check drafts first, turn on Settings → General → Check drafts in a panel first: the draft then appears in a panel to change by voice ("shorter", "add that I'm free Thursday", "in German"), with Shorter, Longer, More formal and Warmer, or by typing, with every version kept, then Insert, Copy or Read aloud. With text selected, the draft answers that text and appears in the panel. Dashes between words become commas, so drafts don't read as written by an AI. It never makes up names, dates, numbers or your details: it leaves a [placeholder] to fill in. Instructions for an AI hidden in the message you're answering are left out before anything is written. Every "write…" goes through Compose too, so a short "write a polite no" also sees the conversation. A letter that always writes a draft (dictation key + the letter) can be set in Settings → General; there's none by default.

## 0.6.0 — 2026-11-03

- **A clearer, quicker setup guide.**
  - The first page shows what Splashdown is: the demo of a sentence said and typed into an email, "Talk instead of type.", and the dictation key drawn as a key on your keyboard rather than a button.
  - "How should Splashdown work?" offers two choices that fit the window: free and private (runs completely on your computer) or your own API key, with one row for the key.
  - Speech to text comes first, about half a gigabyte, so you can dictate in about a minute. The AI that removes the "um"s, rewrites and answers is optional and downloads in the background while you try things.
  - Try it has five things instead of seven, including dictating into one of your own apps and hearing a message read back ("read this to me", or "read me a summary of this"). The natural voice it reads in (68 MB) comes with the AI, after speech to text.
  - The last page says four things: hold the key in any app, where Splashdown lives, notes and meetings (hold the key and press N to save a thought; record a meeting from the menu bar), and how to see everything else.
- **Settings → Providers is now AI Models**, with Text to speech beside Speech to text and Cleanup & formatting: the same Provider, Voice and "Using now" as the others.
- **Splashdown reads to you.** Select text, hold the dictation key and say "read this to me", and your computer's own voice reads it, with nothing sent anywhere. With nothing selected, tap the instruction key first and the text you're writing is read, or your last dictation. Say "read me a summary of this" (or "read me the action items", "what's the gist of this, read it out") and your AI writes a short answer meant for listening, which is read as it's written, so the voice starts after the first sentence; it also shows in the Ask panel. The Ask panel has a Read aloud button for any answer, and Last dictation → Read it to me checks your last dictation by ear. Music pauses while it reads, and Esc or starting a dictation stops it. Settings → AI Models → Text to speech picks the voice and speed; text in another language gets a voice for that language. Works without voice actions turned on.
- **Natural-sounding text to speech for English.** Settings → AI Models → Text to speech → Provider: On this computer, Phonon 31M (68 MB download) adds 25 voices, American and British, that sound like a person rather than a computer: Phonon by Gradium, open source (Apache-2.0), run on your computer's processor, starting to speak in a fraction of a second even on a slow PC. It reads numbers, dates and amounts as they're said. Once it's downloaded, Automatic reads English in Harper; other languages still get the best system voice for that language. The first time Splashdown reads English without it, it asks once whether to download it. The speed setting is for the system's voices; Phonon reads at its own pace. `splashdown-cli say "…"` reads text with it from the terminal.

## 0.5.1 — 2026-11-02

- **A much faster built-in model on Windows, and on Intel Macs.** It was built for the oldest x86 processors, without the instructions (AVX2, FMA) it relies on, so it ran several times slower than the processor could. Windows now gets two builds: one for processors from about 2013 on that can also use the graphics chip (Vulkan), and one for older processors; Splashdown picks the one that runs, and falls back to the other if the first fails. Intel Macs get the faster instructions too (every Mac macOS 13 supports has them).
- **The setup guide checks whether this computer is fast enough for the built-in model.** Once it's downloaded, Splashdown times it on an ordinary dictation. If tidying up would take more than about 5 seconds (common on older PCs, where it runs on the processor alone), the guide says so and offers a cloud key (OpenRouter: about a second, a few cents a day), turning tidying up off, or keeping it anyway. Between 2 and 5 seconds, it mentions that a cloud key is quicker. Settings → Providers shows the measured speed, and if real dictations turn out slow too, Splashdown suggests a cloud key once.
- **The setup guide waits until Splashdown is ready.** While the models download and the speed is checked, Try it shows the progress, with a capsule drifting down under its parachute, and can't be skipped past: there's nothing to try until it's done.
- **The setup guide asks whether you want voice actions.** Instead of a switch inside a step, the Do things step asks plainly ("Want Splashdown to do things for you, not just type?") with Yes, turn it on and Not now, and the last page asks once more if you skipped past it.

## 0.5.0 — 2026-11-02

- **Voice actions: say what to do, not just what to write.** Turn on Settings → Actions, hold the dictation key, tap the instruction key and say "open Spotify", "search YouTube for paella recipes", "remind me at 3 to call Sam", "add dentist to my calendar on Thursday at 4", "pause the music", "add milk to my to-dos", "email Dana that I'll be ten minutes late" or "start recording the meeting", in any language. Select text first and "email this to Sam" or "add this to my to-dos" uses it. Nothing is ever sent, deleted or bought: an email opens as a draft for you to send, a Shortcut asks before it runs (unless you choose Always allow), and "undo that" takes back an event, reminder or to-do. Each action can be turned off. Works with the built-in model on your computer as well as cloud ones. Events go to your calendar and reminders to Reminders on a Mac; on Windows an event opens in your calendar app to save, and a reminder becomes a to-do in today's note.
- **Your own voice actions.** Settings → Actions → Your actions: give a link, a script or program, or keys to press a name, and say it ("deploy staging", "next slide", "open issue ENG-42"). Put {text} in a link or an argument and what you say goes there: encoded into the link, or passed to the program as one argument, never through a shell. Splashdown shows exactly what will run and asks first, until you choose Always allow (taken back with Ask again, and asked again whenever the action changes). Your actions are on the "What can I say?" page.
- **The setup guide walks you through the main things.** The Try it page now has seven to try, one at a time in one practice box, each ticked off when it actually works: dictate, change selected text, add an instruction, press Return when it's typed, fix it by voice, do things (with the switch to turn voice actions on, and "open Calculator"), and ask a question. Skip any one, or the rest. The last page says how to see everything you can say.
- **A shorter menu bar menu.** The everyday items stay at the top (Notes, Record a meeting, Preset, Language, Settings); Undo AI edit, Paste raw transcript, Copy result and Retry are under Last dictation, and What you can say, Send feedback and Check for updates under Help. "Update to …" appears at the top only when there is one. Whisper mode and the mini bar are switched in Settings → General (or "whisper mode on" by voice).
- **"What can I say?"** Hold the dictation key, tap the instruction key and say "what can I say?" (or "help", in any language with voice actions on), or choose Help → What you can say… in the menu bar, and a window lists everything you can say or press: changing what you just dictated, instructions while you dictate, selected text, questions, voice actions, the keys while you hold the dictation key, and the shortcuts. It names your own keys, and shows only the voice actions that are on (or a button to turn them on). When a command isn't understood, the message says to ask.
- **Music and videos are turned down while you speak, as with Siri.** While you hold the key, other sounds drop to a quarter of their volume and come back when you let go, so you aren't talking over them and they don't leak into the microphone. This is now the default for everyone, including if you used Splashdown before (it was off unless you had chosen it). Settings → General → Other sounds while you speak can mute them instead, pause the music, or leave them as they are. Pause music pauses Spotify and Music on a Mac (macOS asks once whether Splashdown may control each) and any app showing media controls on Windows, browser tabs included, and plays only what it paused again. Where the sound's volume can't be changed, as with many audio interfaces, the music is paused instead.
- **Windows fixes from a review of everything written for Windows.**
  - No console window: the built-in tidy-up model and the link downloader no longer pop one up, and neither does Open Settings for the microphone.
  - Keyboards with AltGr (Polish, Czech, German and others) keep their characters. Ctrl+Alt+V, Z, N or M is no longer taken as a shortcut where AltGr types something with it.
  - Alt or a Windows key as the dictation key no longer opens the app's menu or Start when you let go.
  - Two people signed in at once can each run Splashdown; the second copy used to quit.
  - Starting a meeting from Notes, opening Notes from the meeting bar, and opening the setup guide from Settings could freeze the app; they don't now.
  - Questions such as "Still in a meeting?" no longer take the keyboard from what you're typing in.
  - If the microphone is off for desktop apps, the setup guide says how to turn it on, instead of waiting forever.
  - Opening links, settings pages, files and apps works with any characters in their names.
  - "Open" finds Store apps whose names have accents.
  - "Switch to Notepad" brings the open window forward instead of starting another copy.
  - Downloads, link helpers and notes in a OneDrive or Dropbox folder wait out a virus scanner or sync app holding the file, instead of failing.
  - Stopping a link transcription stops the download too.
  - Installing an update waits until a meeting is stopped, and no longer fails on the built-in model's helper.
  - Text pastes into Git Bash and PuTTY.
  - Arrow keys sent to a Remote Desktop window are no longer read as keypad numbers.
  - The dictation key keeps working while the built-in model is busy.
  - Restoring your clipboard no longer adds the same item to clipboard history again.
- **Spoken commands answer faster with the built-in model.** It now keeps the prompts for tidying up, commands and actions ready at once, without using more memory, so switching between them no longer starts over: a command and its action take about 0.4 s on a Mac instead of 2 s.

## 0.4.0 — 2026-11-01

- **A setup anyone can do.** The first-run guide now asks one thing: set Splashdown up on this computer (free, private, no account), or use an API key if you have one. Set up on this computer, it starts downloading what it needs right away (about 3 GB) and carries on while you allow permissions, with one progress bar that says how long is left. You can try dictating as soon as the part that understands you arrives; tidying up switches on by itself when its download finishes, even if you close the guide. It checks for disk space first, and a download that stops is one click from carrying on.
- **The best models your computer can run, by default.** Splashdown now uses its own speech model (Nemotron) and tidy-up model (Qwen3 4B) rather than Apple's built-in ones when they're downloaded: in our tests they make about half the speech errors, and tidy up better (85% of cases against 72%). On a computer with less than 12 GB of memory, tidying up uses Apple Intelligence where the Mac has it, and otherwise a new compact Qwen3 4B (1.7 GB), which tidies up far better than the old small model (74% of cases against 55%) in about as much memory; it's in Settings → Providers too.
- **Only one copy of Splashdown runs at a time.** Opening it again while it's running (from the Start menu, say) now shows its Settings instead of starting a second copy. Two copies both answered the dictation key, so what you said was typed twice, once garbled.
- **Model downloads you can count on.** Download for the built-in cleanup model in Settings → Providers works again: it showed no progress, and once done it was mistaken for the speech model, so Splashdown said a model wasn't downloaded (this is put right on its own after updating). A download that stalls or drops now carries on from where it stopped, by itself or the next time you click Download, instead of starting over or hanging; progress bars show in Settings, and a download keeps showing if you close Settings and open it again.

## 0.3.0 — 2026-11-01

- **The status pill at the text cursor on Windows.** As on a Mac, the pill now shows just below where you're typing (above it near the bottom of the screen), not only at the bottom center, in classic Windows apps and in browsers, Office and other apps that report their text cursor to accessibility tools. Settings → General → Show the status next to the text cursor turns it off.
- **Transcribe a meeting again with another model.** When a meeting's or recording's audio is kept with its note, Transcribe again… in the note's ⋯ menu (or ⌘K) runs it through another downloaded speech model, such as Whisper large-v3-turbo for a call in another language, or the one in Settings. The new transcript takes the old one's place, with the progress and Stop of a file transcription; speakers keep the names you gave them, and My notes and the summary stay as they were. Stopped part way, the note is left as it was.
- **Ask finds notes by meaning.** Turn on Settings → Notes → Find notes by meaning, and Ask (in Notes, and with the ask key) finds the notes about what you mean, not only the ones with the same words: "why was the launch delayed?" finds the note that says it was pushed back to March, in any of over 100 languages. Notes are ranked by both their words and their meaning. It runs on your computer with the Qwen3 Embedding model, downloaded once (about 639 MB); your notes are read once in the background, and again only when they change.
- **Speaker names in meetings.** Turn on Settings → Notes → Meetings → Tell the other people apart, and when a meeting ends, the other side's turns are split into Speaker 1, Speaker 2 and so on (up to four); a recording of the room gets the same. Click a speaker in the Transcript tab to name them, from the people on the calendar invite or by typing, and every turn they said, and their action items, take the name. It runs on your computer with NVIDIA's Sortformer model, downloaded once (about 139 MB); an hour's call takes under a minute.
- **Meetings named from your calendar (Mac).** Turn on Settings → Notes → Meetings → Name meetings from my calendar, and a meeting note takes the title of the calendar event on when it starts and says who else is invited, instead of "Meeting · Nov 1". The calendar is read on your Mac only; macOS asks first.
- **Today's note and smart views.** Today's note (⌘T) opens today's daily note in Notes, making it if it isn't there yet (the folder and name are the ones set for captures in Settings → Notes). Beside Pinned, the column has To do (notes with an unticked checkbox), Changed today and Untagged.

## 0.2.0 — 2026-11-01

- **A redesigned Notes window.** Record a meeting, Transcribe (a file or a link) and Ask sit in the toolbar instead of a menu, and ⌘K finds any note or anything the window can do. Notes show their formatting as you write: headings, bullets, and checkboxes you can click, while the file stays plain Markdown. The list shows what each note is (a meeting, a transcript, a dictation) and filters to pinned notes, meetings or transcripts; each note's ⋯ (or a right-click) pins, renames, shows or trashes it. A new, empty note shows the ways to fill it, and pasting a link into one offers to transcribe it. **Paste into {app}** (⌘↩) replaces Send to, and follows whichever app you used last. Notes is now an ordinary window; ⋯ → Keep on top floats it over other apps, as the scratchpad did.
- **Folders and tags in Notes.** A column beside the list has All notes, Pinned, Meetings & recordings and Transcripts, then your folders, nested as deep as you like, and your tags. Folders are real folders in your notes folder (Obsidian and Finder see the same ones): create, rename, nest and trash them from their ⋯ menu, and move a note by dragging it onto a folder or with Move to…. A new note goes into the folder you're looking at. Tags work the way Obsidian's do: write `#tag` anywhere in a note, or add one above it, nested with `/` (`#work/acme`); the tags column shows them as a tree with counts, and ⌘-click on a tag in a note shows its notes. ⌘K finds folders and tags too, and ⌘⇧E shows or hides the column.
- **Rewrites you can check before keeping.** Clean up, Email and your other transforms sit under the note. The result shows what changed, words taken out struck through and new ones highlighted, and you keep it, keep the original, or say what to change ("warmer", "in French") and try again. **Say how…** rewrites in your own words without a saved transform. Each try stays until you choose, and the note before is in Versions.
- **Ask your notes from Notes.** ⌘J opens Ask beside the note: ask about this note or all of them. Answers mark which notes they came from, and a click opens one. Follow-ups carry on the conversation; Add to this note puts an answer in.
- **Meeting notes in tabs: Summary, Transcript and My notes.** While a meeting records, Notes shows the transcript as it grows, with a place beside it to write your own notes; the summary covers what you wrote down first. **What did I miss?** answers from the last few minutes. Afterwards, a kept recording plays in the note: click a turn's time to hear it. Summarize again rewrites the summary.
- **Much faster local speech-to-text.** A new engine runs NVIDIA's Nemotron and Parakeet models as well as Whisper. The new default, Nemotron 3.5, transcribes while you speak in any of 32 languages, so your text is ready almost the moment you let go of the key, and it shows the words as you speak. Nemotron (English) is offered too, and Whisper large-v3-turbo is the most accurate for other languages. Models download when you choose them (Settings → Providers → Speech to text → On this computer), and a model is only loaded once you've chosen it; Splashdown says when it's still loading. The live words while you speak now need speech-to-text on your computer. A Whisper model downloaded before needs downloading again in the new format.
- **Text appears sooner with a cloud AI.** The AI's text is typed into the app as it's written, starting a moment after you let go of the key, instead of all at once at the end. If the final version differs (the AI went too far and your words are used instead), the end is corrected. Settings → General → Type the AI's text as it's written turns it off.
- **Ask a question and get an answer instead of typed text.** Hold the dictation key, press A and ask: "what's the German word for deadline?", or select text first and ask "what does this say?". The answer appears in a small panel with Copy and Insert. Answers can draw on your notes ("what did we decide about the launch?"); turn that off in Settings → Privacy. A question said after the instruction key, with nothing dictated, is answered the same way. Ask a follow-up by typing it into the panel, or by asking again while it's open. Also `splashdown-cli ask`.
- **Transcribe an app's audio.** Notes → Transcribe → An app's audio… lists the apps playing sound (a browser with a webinar, a podcast app, a video call you're only listening to) and transcribes what the chosen one plays into a note as it plays, with My notes beside it and a summary at the end. Only that app's sound is recorded, not the microphone or other apps, so headphones are fine. A level meter shows what it's getting, with "Hearing words", "Sound, no words yet" or "No sound from …" beside it. "All of this computer's sound" is there too. macOS 14.2 or later; on Windows, Windows 10 version 2004 or later.
- **Transcribe the microphone.** Notes → Transcribe → The microphone transcribes a lecture, a talk or a conversation in the room into a note as it's said, hands-free, as plain timed paragraphs (Record meeting would label everyone in the room "You"). Stop it from the note or the menu bar.
- **Transcribe a link.** Notes → Transcribe → A link… takes a link to an audio or video file, or a page such as YouTube. For pages, Splashdown offers to download a small helper the first time (yt-dlp and QuickJS, about 39 MB) and keeps it up to date; nothing else needs installing. The download is deleted once the note is written.
- **App icons in Settings on Windows**, next to each app in Presets, as on the Mac.
- **Share presets.** Share… on a preset saves it as a small file; anyone can add it with New preset → Import a preset file….
- **A second-choice microphone.** Settings → General: if your chosen microphone isn't connected, Splashdown uses the one you pick next (say, the laptop's own) before falling back to Automatic. Meetings follow the same choice.
- **Pin history entries** to keep them at the top and out of automatic deletion.
- **A dictation is never lost.** If speech-to-text or the AI fails (you're offline, a provider is down) or Splashdown closes before it's done, the recording is kept, and **Retry last dictation** in the menu bar turns it into text and copies it. Only that one recording is kept, even with history off.
- **Better at telling speech from everything else.** A small built-in speech detector (Silero) now decides where you're speaking, so quiet or whispered speech is no longer trimmed away, music and noise aren't turned into made-up words, and long recordings are cut between words. It works with every speech-to-text choice and runs on your computer.
- **Notes replace the scratchpad.** ⌃⌥N opens Notes. Each note is a plain Markdown file in `Documents/Splashdown Notes`, or any folder you choose, such as an Obsidian vault or iCloud Drive. Notes has search, pins, earlier versions you can restore, and Show in Finder. Deleted notes go to the Trash. Your scratchpad notes move in the first time you open it.
- **A recording bar for meetings.** While a meeting records, a small bar at the top of the screen shows the time and both sides' levels, with Stop. It's on by default on Windows; on a Mac the menu bar shows the time, and the bar can be turned on in Settings → Notes → Meetings (handy when the notch hides the menu bar icons).
- **Offers to record when a call starts.** When Zoom, Teams, Slack, FaceTime, Meet in a browser or another call app starts using the microphone, a small panel offers to record the meeting, and offers to stop when the call ends. Nothing is recorded until you click; Settings → Notes → Meetings turns it off.
- **Meeting notes.** Press ⌃⌥M (or Record a meeting in the menu bar or Notes) during a call. Splashdown records your microphone and what your computer plays, with no bot joining, and writes the conversation into a note in Meetings as it goes, each turn marked You or Them. When it ends, a summary of decisions, action items and open questions goes at the top (with a cloud AI, it asks first). If Splashdown closes mid-meeting, it offers to finish the note next time. Also `splashdown-cli meeting start`, `stop` and `status`.
- **Transcribe audio and video files.** Drop a voice memo, interview or video onto Notes (or use Transcribe → A file…) and it becomes a note, with the time in the file at the start of each paragraph. It uses the speech-to-text you dictate with, so with a model on your computer nothing leaves it. Reads MP3, M4A, WAV, FLAC, OGG, MP4 and MOV, among others. Also `splashdown-cli transcribe-file`.
- **Dictate straight into a note.** Hold the dictation key and press N: what you say is added to your Inbox (or today's daily note, or the last note opened) instead of typed. ⌃⌥Z takes it back. Also `splashdown-cli note`, `splashdown://note`, and **Save to notes** in History.
- **Notes for coding agents.** If you allow it (Settings → Privacy, off by default), agents set up with `splashdown-mcp` can search and read your notes, and add to them.
- **Transforms.** Saved instructions you run without speaking: Clean up, Summary, To-dos, Email, Prompt for an AI and Meeting summary, or your own (Settings → Words). In Notes they work on the note or the selected text, and ⌘Z or History undoes them. Give one a shortcut and it works on the selected text in any app.
- **A fuller command line.** `splashdown-cli status`, `settings get` and `set` (by key, like `general.language`), `models use` and `history` for scripts, with exit codes they can rely on.
- **Bring your words from another dictation app.** Settings → Words & language → Import… (or `splashdown-cli words import <file>`) adds the vocabulary, corrections and snippets from another app's export, a word list or a CSV file, without changing what you already have.
- **Earlier dictations as context.** What you dictated into the same app in the last few minutes goes along with the next dictation, so "it" and "that" make sense and names are spelled the same way. Kept in memory only; switch it off in Settings → Privacy.
- **Other sounds while you speak.** Settings → General can turn music and videos down or mute them while you hold the key, and put them back afterwards.
- **Fewer made-up words.** A small speech detector checks a recording has a voice in it before it's transcribed, so a fan or a click no longer comes back as "Thank you." Local Whisper output that only repeats its vocabulary hints is dropped.
- **The last word isn't cut off.** Recording carries on for a moment after you let go of the key.
- **New lines don't send messages.** Presets that type instead of paste send line breaks as Shift+Return, which chat apps take as a new line. Terminals still get Return.

## 0.1.0 — 2026-10-30

The first public release.

**Dictation**
- Hold Right Option (Right Ctrl on Windows), speak, let go: the text appears in whatever field has focus, in any app or website.
- An optional AI pass removes "um"s and false starts, at the cleanup level each preset chooses (none, light, medium, high). Spoken formatting ("new paragraph", "comma") works in any language.
- Instructions while dictating (tap Right Shift, then say "make it a bulleted list"), and rewriting selected text by voice.
- Spoken commands in any language: tap Right Shift first, then say "delete that last sentence", "make that more formal" or "send it".
- Hands-free (hold the key and press H), whisper mode for speaking quietly, live text while you speak, and mixed-language dictation.

**Presets**
- Default, Email, Texting, Work chat, Code & Terminal and Notes, matched by app, window title or website. Each sets tone, cleanup, language, translation, its own AI model, auto-send and a shortcut.

**Providers and privacy**
- Your own OpenAI, OpenRouter or Anthropic key with a monthly spending limit, or fully on your computer: Apple's on-device models, or local Whisper plus the built-in local model. Ollama and LM Studio work too.
- When a cloud provider fails, the dictation is retried on your computer.
- No servers, no account, no telemetry. History is off by default.

**And more**
- History, snippets, a vocabulary that learns from your corrections, Insights, a scratchpad, a mini bar, Undo AI edit, `@file` mentions for coding agents, a CLI, `splashdown://` links and an MCP server.
- Mac: signed and notarized, universal (Apple Silicon and Intel), macOS 13 or later. Windows: preview, unsigned.
